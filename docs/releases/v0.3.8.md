Updated Windows packaging with the refined Structural Design Toolkit application icon.

## New: updated Windows application icon

The packaged `sdt.exe` now uses the blue SDT engineering badge icon with structural accents. The icon is included in the Windows executable and regenerated during the release build.

## Download and run

1. Download `sdt-0.3.8-windows.zip` below and unzip it. Keep the files of the `sdt` folder together.
2. Double-click `sdt.exe`, then run `doctor` first.

No Python is needed. ETABS is needed for the ETABS commands, and a LaTeX distribution such as MiKTeX for the PDF reports.
