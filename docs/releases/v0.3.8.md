## New: an icon for sdt.exe

`sdt.exe` now shows its own icon in File Explorer, on the taskbar and on a shortcut: a dark tile with an amber border and the letters SDT under a distributed load. The T is drawn as a T-beam section with its bars, and the D holds a moment diagram.

The small sizes are simpler so that they stay readable: no bars at 32 pixels and below, and the letters alone at 24 and 16.

The icon added in the pull request before this one is removed.

## Download and run

1. Download `sdt-0.3.8-windows.zip` below and unzip it. Keep the files of the `sdt` folder together.
2. Double-click `sdt.exe`, then run `doctor` first.

No Python is needed. ETABS is needed for the ETABS commands, and a LaTeX distribution such as MiKTeX for the PDF reports.
