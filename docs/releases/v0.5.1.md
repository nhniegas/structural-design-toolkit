The dialogs and the PDF calculation reports have a new look, and two faults of `sdt irregularity` are corrected. **If you ran `sdt irregularity` with v0.5.0, run it again**: see "Corrected".

## Changed: the dialogs

- Every window of the toolkit (choices, values, lists, progress, summary, warnings) now has one look, that of the program's icon: graphite, light text, and amber for the mark, the choice made and the confirm button. They carry the program's icon and a dark title bar.
- **A choice:** the question in bright text, its explanation in grey under it. Up and Down move the choice, and a double click on an option confirms it.
- **Cancel:** every dialog that asks has a Cancel button, and Escape cancels. As before, cancelling stops the command with nothing changed.
- **Two lists:** each list shows its count, a double click moves an item, and items keep their order when several are moved. Confirming with nothing selected says so in the window.
- **Summary:** what needs attention is in red, "Nothing needs attention" in green, and a **Copy** button puts the whole summary on the clipboard.
- **Warnings** are a window of the toolkit, no longer the grey Windows message box.
- File and folder pickers stay those of Windows.

See `docs/dialogs.md`.

## Changed: the calculation reports

- The five PDF reports (`sdt beams`, `sdt columns`, `sdt steel`, `sdt composite`, `sdt wind`) share one format.
- **Every page** has a header with the `SDT` mark, the title, the design code, the model or section, the date and "Page x of y", and a footer with the version, the command and the file name.
- **The first page** opens with a title block and the design basis set two to a line.
- Section titles sit on a grey band; tables have a grey head and light rules; a result is a green `PASS` or a red `FAIL` tag beside its ratio.
- One sans typeface for the text and the equations, with wider margins.
- A table too wide for the page is wrapped and scaled to fit; none runs off it.
- **Column report:** each column starts on a new page, and its interaction surface is set beside the transverse reinforcement table, so no page is left half empty.
- The values, the checks and the column interaction surfaces are those of before. The beam and column reports still hold tables of values for each member, with no equation written out for each.
- The format uses a few more LaTeX packages (`fancyhdr`, `lastpage`, `colortbl`, `tgheros`, `sansmath`). MiKTeX installs them on first use; without one, the report is written plainer, not stopped.

See `docs/calculation_reports.md`.

## Corrected

- **`sdt irregularity` checked a seismic case in the wrong direction.** ETABS lists each seismic case in both directions. Across its own direction a case hardly moves the structure, and the ratio of two such small drifts is meaningless: an X case could be reported as a torsional irregularity in Y, with a ratio of 5 beside an Ax of 1.00. Each case is now checked in its own direction only, in the torsion, soft story and stability checks. A model whose ETABS tables list only the own direction, such as the test model, gave the right result before.
- **The equations of `sdt irregularity` and `sdt quantities`** were printed as LaTeX source (`\delta_{max}`). They are now printed with symbols, like those of the other commands.
- **Equations of every command.** What was still written as source is now written as it is read:
  - A subscript the terminal has no small letter for (b, c, d, f, g, w, z, and capitals) is written beside its symbol, as engineers type it: `Ag`, `bf`, `tw`, `φc`, `Lb`, `Mcx`, in place of `A_g`, `b_f`, `t_w`. This shows most in `sdt steel`.
  - `ΔM = 0.7 R ΔS`, `TA`, `Vstatic / Vspectrum`, `qz = Kz q` and `EIeff`, in place of `Δ_M`, `T_A`, `V_static`, `q_z`, `EI_eff` (`sdt check`, `sdt analyze`, `sdt drift`, `sdt wind`, `sdt composite`).
  - Exponents are raised: `hₙ³⁄⁴`, `87.60⁰·⁷⁵`. An exponent that is itself an expression keeps its mark, `0.658^(Fy/Fe)`, since without it the value would read as a product.
  - The text reports of `sdt drift` and `sdt analyze` use the same notation. No number changes.

## Download and run

1. Download `sdt-0.5.1-windows.zip` below and unzip it. Keep the files of the `sdt` folder together.
2. Double-click `sdt.exe`, then run `doctor` first.

No Python is needed. ETABS is needed for the ETABS commands, and a LaTeX distribution such as MiKTeX for the PDF reports.
