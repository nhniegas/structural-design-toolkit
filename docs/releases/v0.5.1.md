The dialogs have a new look. Nothing changes in what the commands ask, calculate or write.

## Changed: the dialogs

- Every window of the toolkit (choices, values, lists, progress, summary, warnings) now has one look, that of the program's icon: graphite, light text, and amber for the mark, the choice made and the confirm button. They carry the program's icon and a dark title bar.
- **A choice:** the question in bright text, its explanation in grey under it. Up and Down move the choice, and a double click on an option confirms it.
- **Cancel:** every dialog that asks has a Cancel button, and Escape cancels. As before, cancelling stops the command with nothing changed.
- **Two lists:** each list shows its count, a double click moves an item, and items keep their order when several are moved. Confirming with nothing selected says so in the window.
- **Summary:** what needs attention is in red, "Nothing needs attention" in green, and a **Copy** button puts the whole summary on the clipboard.
- **Warnings** are a window of the toolkit, no longer the grey Windows message box.
- File and folder pickers stay those of Windows.

See `docs/dialogs.md`.

## Download and run

1. Download `sdt-0.5.1-windows.zip` below and unzip it. Keep the files of the `sdt` folder together.
2. Double-click `sdt.exe`, then run `doctor` first.

No Python is needed. ETABS is needed for the ETABS commands, and a LaTeX distribution such as MiKTeX for the PDF reports.
