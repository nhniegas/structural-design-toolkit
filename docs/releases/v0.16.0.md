Fixes found while designing and retrofitting the RP Antipolo Exp 2 buildings (2026-11-04 to 2026-11-14): crashes on members the toolkit did not expect, answers that were not remembered, and code rules that were applied too broadly.

## Load combinations and the seismic system

- **f1 per live pattern (NSCP 203.3.1).** f1 is 1.0 for floors in places of public assembly, live loads above 4.8 kPa and garage live load, and 0.5 for other live loads. Before, every live pattern took 0.5. `sdt setup` now asks f1 for each live pattern. On an open model, each pattern shows its largest area load, and a pattern loaded above 4.8 kPa starts at 1.0. `sdt check` warns when a live pattern loaded above 4.8 kPa has f1 = 0.5 in the seismic strength combinations.
- **Steel systems (NSCP Table 208-11B).** `sdt setup` and `sdt check` now offer the steel systems beside the concrete ones, with their R, Ω0 and height limits read from the code. For example, SB3 is special concentrically braced frames, with R 6.0, Ω0 2.2 and a 30 m limit in zone 4. Before, a braced building's R had to be typed into the model by hand.
- **Load cases with another name.** When a pattern's load case has another name (pattern `LOUVERS PARIS`, case `LOUVERS`), `sdt setup` now combines that case, and the summary lists it. Before, those combinations failed.
- **ρ with braces (NSCP 208.6.1).** `sdt analyze` now takes ri of a braced frame as the largest horizontal force of a single brace over the story shear. The braces' forces also count in the story shear.

## Design commands

- **Design one group.** `sdt beams` and `sdt design` can design only the frames of one ETABS group, such as the new members of an addition. The forces still come from the whole model. The question is asked only when the model has groups of frames.
- **`sdt beams` keeps the columns.** On a model designed by `sdt design` or `sdt columns`, a later `sdt beams` overwrote the design data and lost the column design. It is now kept while the model file has not been saved since.
- **`sdt design` remembers the beam answers.** The carrier depth, beam torsion, bar spacing and short-span girder answers are now saved, so a later `sdt beams` offers the same choices.
- **Members too shallow to design.** A member too shallow for a top and a bottom layer of bars (such as a 400 × 100 member modelled as a beam) is listed in the summary and left out. Before, it stopped the whole run.
- **Null frames and steel braces.** Frames with the section `None` (rigid links) are skipped by `sdt beams`, `sdt columns` and `sdt drift`, which used to stop on them. Steel braces that ETABS classes as beams no longer stop the joint check of `sdt columns`.
- **No local-axis table.** A model where no frame has a local-axis angle assigned is read with every angle 0. Before, it stopped `sdt beams`.
- **Column slenderness beside walls.** A horizontal member with no concrete section, such as a rigid link to a wall, now supports a column laterally and ends its unbraced length (NSCP 406.2.5). It adds nothing to ψ. Before, a column tied to a wall by links got lu over several stories (14.5 m) and failed slenderness.
- **`sdt walls` f'c.** `sdt walls` now offers the f'c of the model's wall sections, not a fixed 28 MPa.

## Reports and long runs

- **PDF reports in folders with `~` in their path.** An output path with a Windows short name (`C:\Users\NAME~1\...`) stopped pdflatex, and no PDF was written. Every report now compiles in its own folder, with the short name made long.
- **Progress when run from an answers file.** There is no loading window then, so a long run (`sdt columns` on hundreds of columns) printed nothing for many minutes. A progress line is now printed every 10 seconds.

## Download and run

1. Download `sdt-0.16.0-windows.zip` below and unzip it. Keep the files of the `sdt` folder together.
2. Double-click `sdt.exe`, then run `doctor` first.

No Python is needed. ETABS is needed for the ETABS commands, and a LaTeX distribution such as MiKTeX for the PDF reports.
