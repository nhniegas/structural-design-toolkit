A command can now run with no dialog, from a file of answers. The results of a command run with its dialogs are the same as before, except the rows the column report shows at pinned column ends (see "Corrected").

## New: answers file

- `sdt <command> --record file.json` shows the dialogs as usual and saves what you answer.
- `sdt <command> --answers file.json` runs the command again from that file: nothing is asked. Each question is printed with the answer it got, and the warnings and the closing summary are printed in the terminal.
- A dialog with no answer stops the command and names its choices. A file can say to take what the dialogs offer instead; each such answer is then marked `(default)`.
- The file only replaces the dialogs. The command runs the same code on the same values.

See `docs/answers_file.md`.

## New: ETABS test runs (for the source code)

`python tools/etabs_run.py scenario.json` starts an ETABS of its own, runs the commands of a scenario on a copy of a model, and compares what they return with a reference: text, counts and whole numbers must be the same, other numbers within 1e-9. The report says how many numbers differed within that tolerance and by how much. An ETABS you have open and the answers remembered on your machine are not touched. See `docs/etabs_test_runs.md`.

On the test model the beam design from an answers file gave the results of the earlier run made with dialogs, to the last digit, and a run with the model in kN-m gave the same results as in N-mm.

## Corrected

- **Column report at a pinned end.** At a pinned column end the analysis leaves a moment of about 1e-13 kN-m, different at each analysis. The row the report showed for a combination with several permutations (wind steps, response spectrum signs) was picked by that leftover, so Pu and phi Mn at such an end changed from one run to the next on the same model. Now a moment under 1e-6 kN-m is no moment, and among permutations with the same utilization the one with the largest axial compression is shown. No check, bar or status changes: the utilization there was 1e-16 and is now 0. The first comparison of two test runs found this.

## Also

- `SDT_SETTINGS_DIR` in the environment names another folder for the remembered answers, and `SDT_ETABS_PID` the one ETABS process the commands may attach to. The test runs use both.

## Download and run

1. Download `sdt-0.3.9-windows.zip` below and unzip it. Keep the files of the `sdt` folder together.
2. Double-click `sdt.exe`, then run `doctor` first.

No Python is needed. ETABS is needed for the ETABS commands, and a LaTeX distribution such as MiKTeX for the PDF reports.
