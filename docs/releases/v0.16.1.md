Marks in order: the column schedule, the results workbooks and the calculation reports now list the members by number, so C2 comes before C10.

## Order of the members

- **Column marks by number.** The column schedule (left to right), `Column Design.xlsx` and the column calculation report now go C1, C1A, C2 … C10, C11, then the planted columns PC1, PC2 …. Before, the marks were sorted as text, so a model with 10 or more marks gave C1, C10, C11, C1A, C2 …. A model with untagged columns gave 1, 10, 100, 1001, 2 …; these now go 1, 2, 10, 100.
- **Beams from the bottom floor up.** `Beam Design.xlsx`, `Deflection.xlsx` and the beam calculation report now take the floors in the order of their elevation, then the type (BX, BY, GX, GY) and the number. Before, the floor part of the name was sorted as text, so `2` and `3` came before `GF`, and `10GX-1` before `2GX-1`. Untagged beams now go by number (3, 20, 100). Each beam keeps its TOP row before its BOTTOM row.
- **Position letters.** A letter after the number is read by length first, so C1Z comes before C1AA (`sdt tag` gives A … Z, then AA).
- **Combinations by number** in the column report: ULS 2 before ULS 10.
- **Designs stored by an older version.** `sdt schedules` puts the marks of a stored design in the new order too, and so does the column calculation report.
- **Lists in the closing summaries** (failing members, resized members, members left out) use the same order.

Only the order changed: on the t34 test model every value of the results is the same as with v0.16.0.

## Download and run

1. Download `sdt-0.16.1-windows.zip` below and unzip it. Keep the files of the `sdt` folder together.
2. Double-click `sdt.exe`, then run `doctor` first.

No Python is needed. ETABS is needed for the ETABS commands, and a LaTeX distribution such as MiKTeX for the PDF reports.
