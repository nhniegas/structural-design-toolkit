A fix release. **Everyone on 0.1.0 or 0.1.1 should update**, and run `analyze` again on models analysed with them.

## Wrong results fixed

**Models that are not in N-mm units (for example kN-m).** The commands passed numbers to ETABS in N and mm while the model expected its own units.

- `analyze` and `design` set the response spectrum scale about 1000 times too large on a kN-m model, with no warning. Every response spectrum force, combination and design result was wrong.
- `check` read the story elevations in the model's units: a height of 0 m and failed period checks.
- `drift` read the base elevation in the model's units: drifts about 1.2 times too large.

Every command now sets the model to N-mm when it attaches to ETABS and puts the model's own units back when it ends. A kN-m model gives the same forces as the same model in N-mm, row for row. The units your ETABS window displays, and the model file, are not affected.

**Accidental torsion after `analyze`.** `analyze` changed the spectrum scale on a locked model. ETABS then gave the new base shear but kept the accidental torsion of the unscaled run, so the story torsion of the response spectrum cases was too small (1.8 % on the test model, up to 7 % on some girder moments). The model is now unlocked first. This affected models in any units. Results of response spectrum combinations are slightly larger than before.

## Crashes fixed

- **A beam too narrow for its stirrup legs** (for example 250 mm wide with 75 mm cover) stopped the whole `beams` run with no output. That beam now fails with the reason, and the others are designed.
- **An output folder that does not exist** made the run fail after all the design work. The folder is now created when it is chosen.

## Safer defaults

- **Deflection combinations.** On a model without `DEF` combinations, the first choice is now a combination with exactly the unfactored factors or, when there is none, "Let the toolkit add it". Before, the first choice could be a factored combination such as 1.4 D, which gives deflections that are too large. The other combinations are listed with their factors.
- **Beam seismic shear Ve.** The gravity combination selected is now the one closest to 1.2 D + f1 L (ACI 318-14 18.6.5.1, NSCP 2015 203.3). Before, it was the first in the list, 1.4 D, which leaves the live load out.
- **Untagged members.** The first choice is now "Design them as they are". Tagging renames the members of the open model and drops its results, so it is no longer what pressing Enter does.

## Known issues, not fixed in this version

From the user test of 0.1.1; they are planned next:

- Beams get enough bars for 150 mm clear spacing on every face (an office rule, not a code limit). This adds steel, which raises the joint shear demand on the columns. It will become an option.
- `drift` at the centre of mass skips a story that has no diaphragm and does not include torsion. Use the outer corners option.
- `setup` on a model that already has load patterns leaves them out of its combinations; `grids` removes existing columns when the story names of the DXF differ from the model's.
- WX and WY may be the same wind pattern in models made by `setup`.
- The capacity shear Ve of a corner column in a short footing-level story can be too large.

## Download and run

1. Download `sdt-0.1.2-windows.zip` below and unzip it. Keep the files of the `sdt` folder together.
2. Double-click `sdt.exe`, then run `doctor` first.

No Python is needed. ETABS is needed for the ETABS commands, and a LaTeX distribution such as MiKTeX for the PDF reports.
