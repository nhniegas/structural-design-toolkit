First release of the Structural Design Toolkit: ETABS automation and structural design checks to NSCP 2015 and ACI 318M-14, run from a terminal with input dialogs.

## Download and run

1. Download `sdt-0.1.0-windows.zip` below and unzip it. Keep the files of the `sdt` folder together.
2. Double-click `sdt.exe`. A terminal opens with the menu of commands.
3. Run `doctor` first: it checks ETABS, the dialogs and LaTeX on your machine.

No Python is needed. Windows may warn that the program is from an unknown publisher (it is not signed): choose **More info**, then **Run anyway**.

You need:

- Windows, and ETABS for the ETABS commands (developed on ETABS 22).
- A LaTeX distribution such as MiKTeX for the PDF calculation reports. Without it the results (`.xlsx`) and schedules (`.dxf`) are still written.

## What is in it

| Command | What it does |
|---|---|
| `setup` | Materials, frame and slab sections, load patterns, UBC 97 response spectrum, load cases and NSCP 2015 combinations |
| `grids` | Stories, grids, columns and walls from a DXF of framing plans |
| `tag` | Unique names for every beam and column |
| `check` | Checks the open model against NSCP 2015 (read only) |
| `analyze` | Runs the analysis, scales the response spectrum, checks periods, modal mass and weight |
| `drift` | Story drift with the drift stiffness, then restores the model |
| `beams` | Beam design to ACI 318M-14: flexure, shear, torsion, deflection, SMRF; schedules and calculation report |
| `deflection` | Beam deflections alone |
| `columns` | Column design: P-M with slenderness, shear, confinement, strong column - weak beam, joint shear |
| `design` | Analysis and design loop that resizes beams and columns until they pass |
| `composite` | Rectangular filled composite column, AISC Design Guide 6 |
| `steel` | Wide-flange steel member, AISC 360-22 |
| `wind` | MWFRS wind pressures, ASCE 7 directional procedure |
| `doctor` | Checks that the machine can run the toolkit |

The commands run on a model made with `setup` and also on a model built by hand or by someone else: they read what the model holds and ask for what is missing. See `docs/existing_models.md` in the zip.

## Not in this version

Planned for later versions:

- Shear wall design (walls are reported as not designed).
- Resizing members for drift in the design loop (drift is checked and reported).
- Column base fixity read from the ETABS supports.
- Steel and composite member design from the ETABS model.
- Flanged beams in the design loop.
- Period, base shear and spectrum scaling checks for seismic loads other than UBC 97.

## Engineering use

These tools automate calculations; they do not replace engineering judgement. Check the results independently before using them for design, and read the limitations section of each guide in `docs/`.
