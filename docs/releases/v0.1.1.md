## What changed

**Column base fixity is read from the ETABS model.** The slenderness check of a column that stands on a support now takes that support as the analysis has it: fixed (ψ = 1.0) when the rotation in the bending direction is restrained, pinned (ψ = 10) when it is not, for each axis. Version 0.1.0 assumed every base fixed, which gave a shorter effective length than a pinned base has.

- The column results have a new field, "Base of the column (ψ at the support)", and the calculation report states the base under the slenderness table.
- A footing joint with no support in the model is taken as pinned.
- Run `sdt beams` again before `sdt columns`: design data stored by 0.1.0 has no supports, so the base is assumed fixed and the report says so.

For a model with pinned bases, k of the columns on the supports is larger than in 0.1.0, so their slenderness ratio and, where they are slender, their magnified moments are larger.

## Download and run

1. Download `sdt-0.1.1-windows.zip` below and unzip it. Keep the files of the `sdt` folder together.
2. Double-click `sdt.exe`, then run `doctor` first.

No Python is needed. ETABS is needed for the ETABS commands, and a LaTeX distribution such as MiKTeX for the PDF reports. See the notes of v0.1.0 for the full list of commands.

## Not in this version

Shear wall design, resizing for drift in the design loop, steel and composite member design from the ETABS model, flanged beams in the design loop, and seismic checks for loads other than UBC 97.
