Two corrections: a PDF report that was not written on a machine without the `lastpage` package, and failing members that were hard to find in the result workbooks.

## Corrected: a report stopped by a missing LaTeX package

- **What happened.** The reports asked MiKTeX for the package `lastpage`, for the "of y" of "Page x of y". On a machine where MiKTeX did not have it and could not install it (no internet, or the install refused), LaTeX stopped and no PDF was written.
- **"Page x of y" needs no package now.** The report writes the number of its last page itself, so `lastpage` is no longer used.
- **A package the report can do without cannot stop it.** The header package, the table colours and the typeface are optional: without one the report is written plainer. When only such packages are missing, the report is compiled with MiKTeX told to install nothing, so no window opens and nothing can fail on it.
- **`sdt doctor` installs the packages.** A new line, `LaTeX packages`, says whether every package the reports use is installed. When MiKTeX lacks some, `sdt doctor` names them and asks whether to install them now (about a minute, with the internet). With TeX Live it gives the command to type.

See `docs/calculation_reports.md`.

## Changed: failing members in the result workbooks

- In `Beam Design.xlsx`, `Column Design.xlsx` and `Deflection.xlsx`, every row of a member that fails is filled light red, and its name and the results that fail are red and bold.
- A beam has two rows (top and bottom) and a column one row for each end and combination: all the rows of the member are marked when any of them fails.
- A member that passes is not coloured. Before, a failing result was in a red font only, in the column workbook and in the deflection check, and nothing marked the name.
- No value changes.

See `docs/concrete_beam_column_design.md`.

## Download and run

1. Download `sdt-0.5.2-windows.zip` below and unzip it. Keep the files of the `sdt` folder together.
2. Double-click `sdt.exe`, then run `doctor` first.

No Python is needed. ETABS is needed for the ETABS commands, and a LaTeX distribution such as MiKTeX for the PDF reports.
